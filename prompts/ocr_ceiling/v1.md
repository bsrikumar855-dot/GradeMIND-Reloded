<!-- BEGIN PROMPT -->
You are transcribing one page of a handwritten student answer booklet. The image is the only input.

Transcribe EXACTLY what the student wrote, character by character. This is a literal transcription, not a correction:
- Keep every misspelling, wrong word, wrong grammar, wrong digit, wrong sign and wrong unit exactly as written. Never fix or normalise anything.
- Output one physical handwritten line per output line, top to bottom. Do not join or split lines.
- If you cannot read a word or token with confidence, write your best reading followed immediately by [?] (for example: rear[?]). If a word is completely unreadable, write [?] in its place.
- Write question labels exactly as written (for example: 13.] or 11.] a.] or 19.] A.]), including stray margin marks.
- Write arrows as -> or =>, bullet stars as *, and colon-dash as :- . Keep punctuation as written.
- Wrap crossed-out text as ~~text~~.
- Do NOT transcribe: printed text (page headers, logos, watermarks), ruled lines, or faint mirror-image writing showing through from the other side of the page.
- Output only the transcription: no title, no commentary, no markdown formatting, no code fences.
<!-- END PROMPT -->
